Release notes

October 2026

Changes listed in these release notes are for the Submit an application to change the Land Register APIs only, and include:

  • New functionality
  • Documentation improvements
  • Deprecation and decommissioning notices

This release includes breaking changes to the Submit an application API.

New functionality

This release introduces the following new functionality.

Contractual controls (breaking change)

New contractual controls legislation (opens in a new tab) takes effect on 6 April 2027.

By this date, all applications submitted to register notices or restrictions must include a declaration stating whether contractual control interests apply and they have been recorded correctly. The following transaction types are affected:

  • AGN - Agreed notice (AN1)
  • AUN - Amendment of unilateral notice (UN3)
  • RXN - Restriction (non-standard wording) (RX1)
  • RXS - Restriction (standard wording) (RX1)
  • UNN - Unilateral notice (UN1)

To comply with regulations, the applicant must choose one of the following options:

  • yes (RELATED_TO_CCR_AND_CCI_SUBMITTED): contractual control interests apply and the contractual control right has been recorded
  • no (NOT_RELATED_TO_CCR): there are no contractual control interests

Failure to submit a declaration will result in an error.

Note:

Customers who request to see the electronic version of the application form (e-AP1) before 6 April 2027 will not see the contractual control data they have submitted. This will only appear from 6 April 2027 onwards.

API updates

  • Submit an application API v2: POST /v2/applications now includes the following transaction types in the transactions.{property name}.details object:

    • AgreedNoticeV2 - Agreed notice (AN1)
    • AmendmentOfUnilateralNoticeV2 - Amendment of unilateral notice (UN3)
    • RestrictionNonStandardV2 - Restriction (non-standard wording) (RX1)
    • RestrictionV2 - Restriction (standard wording) (RX1)
    • UnilateralNoticeV2 - Unilateral notice (UN1)

To comply with contractual controls legislation, each transaction type includes the contractual_control_right_affects_transaction property, which you must set to either RELATED_TO_CCR_AND_CCI_SUBMITTED or NOT_RELATED_TO_CCR.

Note:

All objects in the POST /v2/applications OpenAPI specification have the suffix V2.

Completion data for applications

Previously, the lack of summary data on completion of an application prevented the automation of post-completion activities. Now, when an application has been completed, and you are notified of the status change via the Notifications API, you can either:

  • download the correspondence documents in PDF format
  • retrieve completion data, in JSON format, from the Application information API

For integrators who previously used the XML completion data from the e-Document Registration Service, some object names have been updated.

SOAP object names REST API object names
RegisteredProprietorParty.Q1AddressType[] registered_proprietor_party.address[] (AddressForService)
Title.DocumentDetails document_details (RegisterDocumentDetails)

For early completions, the completion data is only provided when the application’s status is updated to completed. No updates are provided after the discharge transaction is successfully processed.

API updates

  • Application information API: GET /v1/applications/{application_request_id}/information now includes a completion_data section in the response.

Documentation improvements

We have made improvements to the developer pack, including restructuring the site and page content, and adding sub-navigation and breadcrumbs to pages. Expect to see regular updates as we continue this work.

Deprecation and decommissioning notices

Review the following notices. These changes may impact your services.

Deprecation notice

We are deprecating the Submit an application API v1 (POST /v1/applications) because it does not comply with upcoming contractual controls legislation.

Deprecated endpoint Planned retirement date Alternative
POST /v1/applications 6 April 2027 POST /v2/applications

We recommend that you migrate to the alternative endpoint by 6 April 2027.

Decommissioning notice

The Submit an application to the Land Register APIs v0.3 have now been decommissioned.
